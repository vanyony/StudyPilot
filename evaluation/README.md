# 概率论 BM25 基线数据说明

`probability_bm25_v1.json` 是小规模人工核对检索集，只回答：给定短查询，正确课程笔记块能否进入 BM25 Top 5。

- 语料仅含 `D:\笔记\概率论` 下九份 `ch1`—`ch9` 章节知识笔记。
- 不导入答案、解析、真题、真题精讲、操作卡或人工金标准文本。
- 仓库不复制笔记正文，只保存文件名、SHA-256、必要短 query 与标题定位。
- 金标准为“来源文件名 + Markdown 标题”，运行时解析成真实 block ID。
- 文件哈希变化时评测停止，必须人工复核，不能悄悄沿用旧结果。
- 共 30 条人工核对 query：15 条术语明确查询与 15 条语义改写，覆盖九个章节；失败项不按结果修改。

本评测不衡量教学效果、答案正确率或考试提分，也不把 BM25 score 解释为概率。
